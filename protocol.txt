Протокол обмена UART «две ESP32» (NMEA-стиль)
===============================================

Физический уровень
------------------
Интерфейс : UART, 3 провода (TX, RX, GND)
Скорость  : 115200 бод
Формат    : 8 бит, без паритета, 1 стоп-бит (8N1)
Кроссировка : TX одной платы -> RX другой, GND общий


Формат кадра
------------
Каждый пакет — одна строка ASCII:

    $<тип>,<поле1>,<поле2>,...,<полеN>*<HH>\r\n

- `$`        — маркер начала (0x24)
- `<тип>`    — идентификатор сообщения (4 символа)
- поля разделяются запятой `,`
- `*`        — разделитель перед контрольной суммой
- `<HH>`     — XOR всех байт между `$` и `*` (не включая их самих),
               в HEX, 2 символа, верхний регистр
- `\r\n`     — конец кадра (0x0D 0x0A)


Алгоритм контрольной суммы
--------------------------
    uint8_t cs = 0;
    for (каждый байт между '$' и '*') cs ^= байт;
    // вывести cs как "%02X"


Сообщения
=========

1. $SLSD — данные состояния (Мастер -> Дисплей)
-----------------------------------------------
Отправляется мастером периодически, каждые 200 мс (и сразу при изменении).

    $SLSD,<P1>,<P2>,<K1>,<K2>,<alarm>*<HH>

Поле   Тип    Описание                        Диапазон
P1     float  Давление после 1-й ступени, МПа 0.00 ... 5.00
P2     float  Давление после 2-й ступени, МПа 0.00 ... 5.00
K1     int    Команда 1-й ступени             0 = ВЫКЛ, 1 = ВКЛ
K2     int    Команда 2-й ступени             0 = ВЫКЛ, 1 = ВКЛ
alarm  int    Код аварии (см. таблицу)        0 ... 4

Пример: $SLSD,0.75,3.12,1,0,0*17
(P1=0.75, P2=3.12, K1 вкл, K2 выкл, аварий нет)

Расширение (обратно совместимо — приёмник читает первые 5 полей и
игнорирует хвост):

    $SLSD,<P1>,<P2>,<K1>,<K2>,<alarm>,<K3>,<K4>,<state>*<HH>

K3        int    Фактическое состояние реле 3       0 = ВЫКЛ, 1 = ВКЛ
K4        int    Фактическое состояние реле 4       0 = ВЫКЛ, 1 = ВКЛ
state     int    Режим установки                    0 = STOP, 1 = RUN,
                                                    2 = ALARM, 3 = SERVICE,
                                                    4 = пауза повторного
                                                    запуска 2-й ступени

Пример: $SLSD,0.75,3.12,1,0,0,1,0,1*0B


Коды аварий (alarm)
--------------------
0  Нет аварии
1  Аварийный останов / аппаратная защита
2  Неисправность датчика давления
3  Вторая ступень не создаёт давление
4  Первая ступень не создаёт давление


2. $SLSS — уставка и границы диапазона (Дисплей -> Мастер)
----------------------------------------------------------
Отправляется дисплеем при изменении двуручечного слайдера/спинбокса.

    $SLSS,<P2_Set>,<P2_Start>*<HH>

Поле      Тип    Описание                              Диапазон
P2_Set    float  Уставка (верхняя граница), МПа        0.35 ... 4.20
P2_Start  float  Порог повторного включения (нижняя
                 граница), МПа                         0.25 ... 4.10

Гарантии: P2_Start >= 0.25 МПа и P2_Set - P2_Start >= 0.10 МПа.
Шаг изменений — 10 кПа (одна позиция слайдера).

Пример: $SLSS,3.60,3.20*1B
(уставка 3.60 МПа, повторное включение при 3.20 МПа)

Примечание: примеры контрольных сумм в этом документе вычислены XOR-ом
байт между '$' и '*'. Чексумму всегда считать, а не копировать.

Совместимость: первое поле осталось уставкой, поэтому мастер, читающий
только одно поле, продолжает работать как раньше.


3. $SLSC — команда (Дисплей -> Мастер)
--------------------------------------
Отправляется дисплеем по нажатию кнопок и от исполнителя команд Wi-Fi.

    $SLSC,<CMD>[,<аргументы>]*<HH>

CMD             Значение
START           Пуск установки
STOP            Останов (исполняется всегда, даже при аварии)
RESET           Сброс аварии (в UI дисплея пока нет кнопки — поддержать
                на мастере обязательно)
OUT,a,b,c,d     ТЕСТ выходов: K1, K2, реле3, реле4 (1 = вкл, 0 = выкл).
                Source: чекбоксы экрана сервисных настроек. Приходит
                ТОЛЬКО при изменении чекбокса.
TH,n1,v1,n2,v2  Пороги ступеней, кПа: НП/ВП 1-й ступени, НП/ВП 2-й
                ступени. Отправляется при изменении уставки на главном
                экране и при входе в сервисные настройки.
                НП/ВП 2-й ступени = нижняя/верхняя ручка главного
                экрана (минимальный гистерезис 100 кПа).
                Пороги 1-й ступени фиксированы алгоритмом: 600/1000 кПа.
                Кадр СПРАВОЧНЫЙ: источник истины — $SLSS, TH не должен
                перебивать уставку и не хранится как настройка.
ZERO,n          Обнуление модуля давления: n = 1 (датчик P1) или n = 2 (P2).
                Аналог команд "zero 1" / "zero 2" на второй плате.
                Дисплей отправляет кадр только когда давление соответствующего
                контура в пределах +-25 кПа (|P| < 0.025 МПа) и связь свежая;
                кнопки на экране сервисных настроек в остальное время
                неактивны (серые).
                Кроме того, ПЕРЕД КАЖДОЙ командой START дисплей автоматически
                отправляет ZERO,1 и ZERO,2 для тех модулей, где |P| < 25 кПа
                (подготовка включения); если давление выше — кадр не шлётся.
                Мастер обязан ПОВТОРНО проверить давление, прежде чем
                обнулять: при |P| >= 25 кПа кадр игнорировать, ответить ERR.
                Обнуление не сбрасывает аварии и не влияет на уставку.

Семантика OUT (только тест/диагностика, НЕ штатное управление):
  - кадр применяется только в сервисном режиме: установка в STOP,
    P1 и P2 < 0.1 МПа, аварий нет; иначе ответ ERR и выходы не менять;
  - K1/K2 — кратковременное включение компрессоров для проверки,
    обязательно с таймаутом (рекомендуется 60 с);
  - R4 — тест резервного реле с автоотключением (10 с);
  - выход из сервисного режима (START/STOP/авария) обязан снимать
    все тестовые включения;
  - после включения питания мастер сам держит все выходы ВЫКЛ и не
    ждёт этого кадра.

Автоматика реле 3 и реле 4 (не по команде дисплея):
  - R3 = ВКЛ, если K1 ИЛИ K2 в работе (любой компрессор);
  - после выключения обоих компрессоров R3 остаётся ВКЛ ещё 60 с
    (охлаждение), затем ВЫКЛ; повторный пуск отменяет таймер без
    разрыва питания реле;
  - R4 — резерв, штатно всегда ВЫКЛ (в будущем сбросной клапан).
  - фактическое состояние R3/R4 отдаётся в $SLSD (поля K3, K4).

Примеры: $SLSC,START*63
         $SLSC,STOP*3B
         $SLSC,RESET*76
         $SLSC,OUT,1,0,1,1*XX
         $SLSC,TH,600,1000,1100,4200*0E
         $SLSC,ZERO,1*3C
         $SLSC,ZERO,2*3F


3a. $SLSA — подтверждение команды (Мастер -> Дисплей)
-----------------------------------------------------
    $SLSA,<CMD>,OK|ERR*<HH>

Примеры: $SLSA,START,OK*XX
         $SLSA,SLSS,ERR*XX

Пока дисплей этот кадр не разбирает; добавляется для того, чтобы
оператор видел отказ (авария, датчик, недопустимая уставка).


Правила приёма
--------------
1. Читать UART в буфер до `\n`; кадр — строка между `\r\n`.
2. Отбросить кадр, если: нет `$` в начале, нет `*`,
   длина > 256, контрольная сумма не совпала.
3. Разобрать тип по первым 4 символам после `$`.
4. Числа парсить как float/int; при ошибке парсинга кадр отбросить.
5. Проверять диапазоны полей (см. таблицы выше), а не только чексумму:
   XOR слабая проверка (например, OUT,1,1,1,1 и OUT,0,0,0,0 дают
   одинаковую сумму).
6. Неизвестный тип кадра — игнорировать, не падать.
7. Если данных нет дольше 1 секунды — считать связь потерянной
   (на дисплее можно показать «нет связи»), но мастеру управление
   не прекращать: дисплей — только HMI.

Рекомендуемый порядок инициализации (обмен)
--------------------------------------------
1. Мастер стартует, читает датчики, шлёт `$SLSD` каждые 200 мс.
2. Дисплей стартует, получает `$SLSD`, пишет в P1_MPa / P2_MPa.
3. Пользователь двигает слайдер -> дисплей шлёт `$SLSS,<P2_Set>,<P2_Start>`.
4. Кнопка «Пуск/Стоп» -> дисплей шлёт `$SLSC,START` / `$SLSC,STOP`.
5. Чекбоксы сервисного экрана -> `$SLSC,OUT,<K1>,<K2>,<R3>,<R4>`
   (включает в том числе реле 3 и реле 4).
