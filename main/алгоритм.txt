Алгоритм управления двухступенчатой компрессорной установкой

1.	Обозначения

P1 — давление после компрессора первой ступени.
P2 — давление после компрессора второй ступени.
K1 — команда включения компрессора первой ступени.
K2 — команда включения компрессора второй ступени.
P2_Set — заданное пользователем давление после второй ступени.
P2_Start — давление повторного включения второй ступени.
T_Restart2 — пауза перед повторным включением второй ступени, 20 секунд.
T_Diag — время, за которое оценивается изменение давления.
dP1_Min — минимальный рост давления первого контура за время T_Diag.
dP2_Min — минимальный рост давления второго контура за время T_Diag.
Retry2 — количество попыток повторного запуска второй ступени.
Retry2_Max — максимально допустимое количество повторных запусков.
Значения T_Diag, dP1_Min, dP2_Min и Retry2_Max подбираются при наладке с учётом объёма ресивера, производительности компрессоров и нормальной скорости роста давления.

2.	Ограничение пользовательской уставки

Пользовательская уставка ограничивается диапазоном:
1,0 МПа ≤ P2_Set ≤ 4,0 МПа

Если пользователь не указал значение, принимается:
P2_Set = 4,0 МПа

Для уставок выше 1 МПа давление повторного включения второй ступени рассчитывается так:
P2_Start = P2_Set − 0,4 МПа

При этом:
P2_Start не может быть меньше 1,0 МПа

Итоговая формула:
P2_Start = MAX(1,0; P2_Set − 0,4)

Примеры:
Уставка	Повторное включение
4,0 МПа	3,6 МПа
3,0 МПа	2,6 МПа
2,0 МПа	1,6 МПа
1,2 МПа	1,0 МПа

Для уставки ровно 1,0 МПа используется отдельный синхронный режим.
3.	Приоритеты управления

Команды должны обрабатываться в следующем порядке:

1.	Аварийный останов или аппаратная защита.
2.	Неисправность датчика давления.
3.	Достижение давления P2_Set.
4.	Диагностика отсутствия сжатия второй ступенью.
5.	Управление второй ступенью.
6.	Управление первой ступенью.

Команда более высокого приоритета отменяет команды более низкого приоритета.

4.	Запуск установки

После подачи команды «Пуск»:

•	Проверить исправность датчиков P1 и P2.
•	Проверить отсутствие аварий и срабатывания аппаратных защит.
•	Ограничить пользовательскую уставку диапазоном от 1 до 4 МПа.
•	Если P2 >= P2_Set, оба компрессора оставить выключенными.
•	Если P2 < P2_Set, включить оба компрессора:
•	K1 = ВКЛ;
•	K2 = ВКЛ.
Одновременный запуск выполняется только при первом запуске установки или после общего останова по достижению уставки.

При необходимости между запуском первой и второй ступени может быть добавлена технологическая задержка.

5.	Управление первой ступенью

Первая ступень работает по давлению P1 с гистерезисом:

Включение первой ступени
Если P1 <= 0,8 МПа,
то K1 = ВКЛ.

Отключение первой ступени
Если P1 >= 1,0 МПа,
то K1 = ВЫКЛ.

В диапазоне:
0,8 МПа < P1 < 1,0 МПа
состояние компрессора не изменяется.
То есть если компрессор был включён, он продолжает работать до 1 МПа. Если был выключен, он не включается до падения давления до 0,8 МПа.
При достижении давления P2_Set первая ступень отключается независимо от значения P1.


6.	Управление второй ступенью при уставке выше 1 МПа

Включение второй ступени

После первоначального запуска вторая ступень включается повторно при условии:

P2 <= P2_Start и при отсутствии:

•	аварии;
•	неисправности датчика;
•	активной паузы повторного запуска;
•	блокировки после превышения количества попыток.
•	Отключение второй ступени

Вторая ступень отключается при условии:

P2 >= P2_Set

После достижения уставки одновременно отключаются оба компрессора:
K1 = ВЫКЛ;
K2 = ВЫКЛ.

В диапазоне:
P2_Start < P2 < P2_Set
состояние второй ступени не изменяется.

7.	Синхронный режим при уставке 1 МПа

Если:
P2_Set = 1,0 МПа включается специальный режим синхронной работы.

В этом режиме оба компрессора работают как единая группа.

Включение группы
Если давление P2 <= 0,8 МПа,
то включить K1 и K2.

Отключение группы
Если давление P2 >= 1,0 МПа,
то отключить K1 и K2.
При этом давление P1 продолжает контролироваться отдельно. Если P1 достигает 1 МПа, первая ступень должна быть отключена своей защитой от превышения давления, даже если вторая ступень ещё включена.

8.	Диагностика работы второй ступени по давлению

Диагностика выполняется только при следующих условиях:

•	вторая ступень получила команду на включение;
•	P2 < P2_Set;
•	установка не находится в режиме останова;
•	датчики давления исправны;
•	после запуска второй ступени прошло время, необходимое для выхода на рабочий режим.


В начале диагностического интервала сохраняются значения:
P1_StartDiag = P1;
P2_StartDiag = P2.

По окончании времени T_Diag рассчитывается:
dP1 = P1 − P1_StartDiag;
dP2 = P2 − P2_StartDiag.

Неисправность или предполагаемое срабатывание тепловой защиты второй ступени определяется условием:

dP1 >= dP1_Min
И
dP2 < dP2_Min
И
P2 < P2_Set.

То есть первая ступень создаёт давление, но давление после второй ступени практически не изменяется.

9.	Повторный запуск второй ступени

При обнаружении отсутствия роста давления после второй ступени:

Отключить только второй компрессор:
K2 = ВЫКЛ.

Запустить таймер паузы:
T_Restart2 = 20 секунд.

Первая ступень в течение этой паузы продолжает работать по собственным уставкам:
включается при P1 <= 0,8 МПа;
отключается при P1 >= 1,0 МПа.

Увеличить счётчик попыток:
Retry2 = Retry2 + 1.

После окончания 20 секунд повторно включить вторую ступень, если:

P2 < P2_Set и отсутствуют другие аварии.

После повторного запуска начать новый диагностический интервал.

Необходимо ограничить количество автоматических повторных запусков. Например:
Если Retry2 >= Retry2_Max,
то отключить оба компрессора

и сформировать аварию
«Вторая ступень не создаёт давление».

Сброс счётчика Retry2 выполняется после успешного роста давления второй ступени или после ручного сброса аварии.

10.	Диагностика первой ступени

Если первая ступень получила команду на включение, но давление P1 не увеличивается в течение заданного диагностического времени, формируется сообщение:
«Первая ступень не создаёт давление».

При этом необходимо отключить оба компрессора:
K1 = ВЫКЛ;
K2 = ВЫКЛ.

Автоматический запуск второй ступени при отсутствии давления первой ступени запрещается.
Надёжно отличить срабатывание тепловой защиты первой ступени от утечки, обрыва привода или механической неисправности только по датчику давления невозможно. Поэтому данная авария должна обозначать именно отсутствие роста давления, а не однозначное срабатывание тепловой защиты.

11.	Достижение заданного давления

Условие останова установки:

P2 >= P2_Set.
При выполнении условия:
K1 = ВЫКЛ;
K2 = ВЫКЛ;
Retry2 = 0.

Установка остаётся остановленной, пока давление не снизится до порога повторного включения второй ступени:
P2 <= P2_Start.

После этого:
вторая ступень получает разрешение на запуск;
первая ступень запускается при P1 <= 0,8 МПа;
при повторном запуске после общего останова допускается одновременное включение обеих ступеней, если это предусмотрено электрической схемой.

12.	Контроль датчиков

Необходимо контролировать:

•	выход значения датчика за физически допустимый диапазон;
•	обрыв датчика;
•	короткое замыкание датчика;
•	отсутствие изменения показаний;
•	слишком резкое изменение давления;
•	потерю связи с аналоговым модулем.
•	При неисправности любого датчика:
•	K1 = ВЫКЛ;
•	K2 = ВЫКЛ.

Формируется соответствующая авария, а автоматический повторный запуск запрещается до восстановления датчика и сброса аварии.

13.	Сводная логика

ЕСЛИ аварийный останов
ИЛИ аппаратная защита
ИЛИ неисправность датчика
ТО:
    K1 := ВЫКЛ;
    K2 := ВЫКЛ;

ИНАЧЕ ЕСЛИ P2 >= P2_Set
ТО:
    K1 := ВЫКЛ;
    K2 := ВЫКЛ;
    Retry2 := 0;

ИНАЧЕ:
    ЕСЛИ P2_Set = 1,0 МПа
    ТО:
        ЕСЛИ P2 <= 0,8 МПа:
            K1 := ВКЛ;
            K2 := ВКЛ;

        ЕСЛИ P2 >= 1,0 МПа:
            K1 := ВЫКЛ;
            K2 := ВЫКЛ;

    ИНАЧЕ:
        ЕСЛИ P1 <= 0,8 МПа:
            K1 := ВКЛ;

        ЕСЛИ P1 >= 1,0 МПа:
            K1 := ВЫКЛ;

        ЕСЛИ P2 <= P2_Start
        И нет паузы повторного запуска
        И нет блокировки второй ступени:
            K2 := ВКЛ;

        ЕСЛИ обнаружено:
            P1 растёт,
            а P2 не растёт
        ТО:
            K2 := ВЫКЛ;
            запустить паузу 20 секунд;
            увеличить Retry2;

        ПОСЛЕ паузы 20 секунд:
            ЕСЛИ P2 < P2_Set
            И Retry2 < Retry2_Max:
                K2 := ВКЛ;

14.	Требование по защите

Диагностика по изменению давления является только косвенным определением неисправности.
Контакты тепловых реле, автоматов защиты двигателя, реле контроля фаз и других аппаратных защит должны работать независимо от логики работы контроллера и разрывать цепь разрешения работы соответствующего компрессора.
Программный анализ давления не должен заменять аппаратную тепловую защиту.
