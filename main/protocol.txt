Протокол обмена UART «две ESP32» (NMEA-стиль)
===============================================

Физический уровень
------------------
Интерфейс : UART, 3 провода (TX, RX, GND)
Скорость  : 115200 бод
Формат    : 8 бит, без паритета, 1 стоп-бит (8N1)
Кроссировка : TX одной платы -> RX другой, GND общий


Формат кадра
------------
Каждый пакет — одна строка ASCII:

    $<тип>,<поле1>,<поле2>,...,<полеN>*<HH>\r\n

- `$`        — маркер начала (0x24)
- `<тип>`    — идентификатор сообщения (4 символа)
- поля разделяются запятой `,`
- `*`        — разделитель перед контрольной суммой
- `<HH>`     — XOR всех байт между `$` и `*` (не включая их самих),
               в HEX, 2 символа, верхний регистр
- `\r\n`     — конец кадра (0x0D 0x0A)


Алгоритм контрольной суммы
--------------------------
    uint8_t cs = 0;
    for (каждый байт между '$' и '*') cs ^= байт;
    // вывести cs как "%02X"


Сообщения
=========

1. $SLSD — данные состояния (Мастер -> Дисплей)
-----------------------------------------------
Отправляется мастером периодически, каждые 200 мс (и сразу при изменении).

    $SLSD,<P1>,<P2>,<K1>,<K2>,<alarm>*<HH>

Поле   Тип    Описание                        Диапазон
P1     float  Давление после 1-й ступени, МПа 0.00 ... 5.00
P2     float  Давление после 2-й ступени, МПа 0.00 ... 5.00
K1     int    Команда 1-й ступени             0 = ВЫКЛ, 1 = ВКЛ
K2     int    Команда 2-й ступени             0 = ВЫКЛ, 1 = ВКЛ
alarm  int    Код аварии (см. таблицу)        0 ... 4

Пример: $SLSD,0.75,3.12,1,0,0*3F
(P1=0.75, P2=3.12, K1 вкл, K2 выкл, аварий нет)


Коды аварий (alarm)
--------------------
0  Нет аварии
1  Аварийный останов / аппаратная защита
2  Неисправность датчика давления
3  Вторая ступень не создаёт давление
4  Первая ступень не создаёт давление


2. $SLSS — уставка (Дисплей -> Мастер)
--------------------------------------
Отправляется дисплеем при изменении уставки (слайдер/спинбокс).

    $SLSS,<P2_Set>*<HH>

Поле     Тип    Описание          Диапазон
P2_Set   float  Уставка P2, МПа   1.00 ... 4.00

Пример: $SLSS,3.60*XX


3. $SLSC — команда (Дисплей -> Мастер)
--------------------------------------
Отправляется дисплеем по нажатию кнопок.

    $SLSC,<CMD>*<HH>

CMD      Значение
START    Пуск установки
STOP     Останов
RESET    Сброс аварии

Примеры: $SLSC,START*XX
         $SLSC,RESET*XX


Правила приёма
--------------
1. Читать UART в буфер до `\n`; кадр — строка между `\r\n`.
2. Отбросить кадр, если: нет `$` в начале, нет `*`,
   длина > 128, контрольная сумма не совпала.
3. Разобрать тип по первым 4 символам после `$`.
4. Числа парсить как float/int; при ошибке парсинга кадр отбросить.
5. Если данных нет дольше 1 секунды — считать связь потерянной
   (на дисплее можно показать «нет связи»).


Рекомендуемый порядок инициализации (обмен)
--------------------------------------------
1. Мастер стартует, читает датчики, шлёт `$SLSD` каждые 200 мс.
2. Дисплей стартует, получает `$SLSD`, пишет в P1_MPa / P2_MPa.
3. Пользователь двигает слайдер -> дисплей шлёт `$SLSS,<P2_Set>`.
4. Кнопка «Пуск/Стоп/Сброс» -> дисплей шлёт `$SLSC,<CMD>`.
